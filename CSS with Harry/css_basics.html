What is CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the presentation of a document written in HTML or XML. CSS is used to control the layout, colors, fonts, and overall visual appearance of web pages. It allows developers to separate content from design, making it easier to maintain and update the look of a website.

How to link CSS to HTML?

There are three main ways to link CSS to HTML:

  • Inline CSS: Using the style attribute within HTML elements.
  • Internal CSS: Using the <style> tag within the <head> section of the HTML document.
  • External CSS: Linking an external CSS file using the <link> tag in the <head> section.

CSS Syntax

CSS syntax consists of a selector and a declaration block. The selector specifies the HTML element to be styled, while the declaration block contains one or more declarations separated by semicolons. Each declaration includes a property and a value, separated by a colon. 

selector {
    property: value;
    property: value;
}

Types of CSS

There are three main types of CSS:

  • Inline CSS: Applied directly to HTML elements using the style attribute.
  • Internal CSS: Defined within a <style> tag in the HTML document's <head> section.
  • External CSS: Stored in separate .css files and linked to HTML documents using the <link> tag.

CSS Selectors

CSS selectors are used to target HTML elements for styling. Common types of selectors include:

  • Element Selector: Targets all instances of a specific HTML element (e.g., p, h1).
  • Class Selector: Targets elements with a specific class attribute (e.g., .classname).
  • ID Selector: Targets a single element with a specific ID attribute (e.g., #idname).
  • Attribute Selector: Targets elements based on their attributes (e.g., [type="text"]).

CSS Properties

CSS properties define the styles that can be applied to HTML elements. Some common CSS properties include:

  • color: Sets the text color.
  • background-color: Sets the background color of an element.
  • font-size: Sets the size of the text.
  • margin: Sets the space outside an element's border.
  • padding: Sets the space inside an element's border.
  • border: Sets the border around an element.

Box Model

The CSS box model describes the rectangular boxes generated for elements in the document tree. It consists of four areas:

  • Content: The actual content of the element (text, images, etc.).
  • Padding: The space between the content and the border.
  • Border: The border surrounding the padding (if any).
  • Margin: The space outside the border, separating the element from other elements.

CSS Positioning

CSS positioning allows you to control the layout of elements on a web page. Common positioning methods include:

  • Static: The default positioning for elements.
  • Relative: Positions the element relative to its normal position.
  • Absolute: Positions the element relative to its nearest positioned ancestor.
  • Fixed: Positions the element relative to the viewport, remaining in the same place during scrolling.
  • Sticky: Toggles between relative and fixed positioning based on the scroll position.

Flexbox

Flexbox (Flexible Box Layout) is a CSS layout module that provides an efficient way to arrange and align items within a container. It allows for responsive design and easy alignment of elements both horizontally and vertically. Key properties of Flexbox include:

  • display: flex; - Defines a flex container.
  • flex-direction: row | column; - Sets the direction of the flex items.
  • justify-content: flex-start | center | space-between; - Aligns items along the main axis.
  • align-items: stretch | center | flex-start; - Aligns items along the cross axis.

Grid Layout

CSS Grid Layout is a powerful layout system that allows for the creation of complex, responsive web designs using a two-dimensional grid-based approach. Key properties of CSS Grid include:

  • display: grid; - Defines a grid container.
  • grid-template-columns: Defines the number and size of columns in the grid.
  • grid-template-rows: Defines the number and size of rows in the grid.
  • grid-gap: Sets the spacing between grid items.
  • grid-area: Assigns a grid item to a specific area of the grid.

Responsive Design

Responsive design is an approach to web design that ensures web pages render well on a variety of devices and screen sizes. Techniques for achieving responsive design include:

  • Media Queries: CSS rules that apply styles based on the device's characteristics, such as screen width.
  • Flexible Grids: Using relative units like percentages for widths instead of fixed units like pixels.
  • Flexible Images: Ensuring images scale appropriately within their containing elements.

CSS Frameworks

CSS frameworks are pre-prepared libraries that provide a foundation for building responsive and visually appealing web designs quickly. Popular CSS frameworks include:

  • Bootstrap: A widely-used framework that offers a responsive grid system, pre-designed components, and JavaScript plugins.
  • Foundation: A responsive front-end framework that provides a flexible grid system and various UI components.
  • Bulma: A modern CSS framework based on Flexbox, known for its simplicity and ease of use.
  • Tailwind CSS: A utility-first CSS framework that allows for rapid custom design without writing custom CSS.
